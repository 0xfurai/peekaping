## Architecture

Peekaping is built with modern technologies:

- **Backend**: Go with strong typing and dependency injection
- **Frontend**: React with TypeScript
- **Database**: SQLite or PostgreSQL for data persistence
- **Real-time**: WebSocket connections for live updates
- **API**: RESTful API with OpenAPI documentation
- **Deployment**: single mode, one process with no Redis, is the default for new installs. Cluster mode, with separate API and probe processes (the API replicas talk through Redis, and the probes run the checks), is for installs that need to scale out, on Kubernetes with Helm or with Docker Compose. See [Deployment modes](./self-hosting/deployment-modes.md)

## Why Peekaping?

Peekaping is designed as a modern alternative to Uptime Kuma, built with a focus on:

- **Strongly Typed Architecture** - Both Go backend and TypeScript frontend
- **Extensibility** - Modular design for easy feature additions
- **Performance** - Go's efficiency enables high performance with low resource usage
- **Developer Experience** - Clean code structure and comprehensive documentation
