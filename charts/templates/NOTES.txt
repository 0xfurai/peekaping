Peekaping is installed as release {{ .Release.Name }} in the {{ .Release.Namespace }} namespace, in cluster mode: api and web deployments, and probe pods that run the checks and talk to the api. The api replicas share the database and talk through Redis.

Check that the pods are running:

  kubectl get pods --namespace {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

The storage backend, Redis, ingress and upgrades are covered on the Helm page:

  https://docs.peekaping.com/self-hosting/kubernetes-helm
